# 图书馆 HTML 项目 — 设计文档

> 日期：2026-08-13
> 目的：为「分支管理 & 合并冲突」练习量身定制的纯 HTML 工程。

## 一、设计目标

让多位同学在同一个仓库上并行开发，体验完整的 Git 协作流程：

1. **干净合并**：各人负责的模块文件互不交叉，分支合并时无冲突。
2. **真实冲突**：在共享文件（`style.css` / `README.md`）上必然撞车，练习冲突识别与解决。

## 二、目录结构

```
book/
├─ index.html        ← 书籍页面（= 首页）【模块A；含全站导航 → 轻度共享】
├─ about.html        ← 图书馆介绍【模块B，独立文件 → 干净合并】
├─ librarian.html    ← 图书管理员介绍【模块C，独立文件 → 干净合并】
├─ css/
│  └─ style.css      ← 共享样式表【所有人追加样式 → 冲突点 ①】
├─ README.md         ← 项目说明 + 分支练习指南 + 贡献者名单【所有人编辑 → 冲突点 ②】
└─ .gitignore
```

### 关键约定：首页 = 书籍页面

`index.html` 同时充当**首页**（含顶部导航跳转其他模块）与**书籍模块**主体内容。
纯 HTML 没有模板包含机制，因此导航栏在每个页面各自复制，归各页面维护——导航本身不构成跨文件冲突。真正的冲突点集中在 `style.css` 与 `README.md`。

## 三、模块内容（丰富中文）

### 模块 A — `index.html`（书籍页面 / 首页）
- 顶部导航栏（首页·书籍 / 图书馆介绍 / 管理员介绍）
- 欢迎横幅
- 书籍卡片列表（约 8 本）：书名 / 作者 / 分类 / 简介 / 馆藏地 / 借阅状态 / 封面占位
  - 《活着》余华、《三体》刘慈欣、《百年孤独》马尔克斯、《围城》钱钟书、《小王子》、《人类简史》、《解忧杂货店》、《红楼梦》
- 借阅状态标签（可借 / 已借出）
- 页脚

### 模块 B — `about.html`（图书馆介绍）
- 导航栏 + 图书馆简介（名称 / 历史 / 宗旨）
- 基本信息（开放时间、地址、电话）
- 馆藏规模、楼层分布
- 借阅规则（数量 / 期限 / 续借 / 逾期）
- 馆内服务（自习室、电子资源、读者活动）
- 页脚

### 模块 C — `librarian.html`（图书管理员介绍）
- 导航栏 + 团队简介
- 管理员卡片：馆长 / 文学区 / 科技区 / 儿童区 / 借阅处前台
  - 字段：姓名、职位、负责区域、办公时间、联系方式、个人简介
- 页脚

## 四、冲突设计（练习核心）

### `style.css` 分块
用注释划分区域，每人在自己区块加样式；当多人同时改文件末尾或同一区块时必然冲突：

```css
/* ===== 基础重置 / 变量（共享，勿乱改）===== */
/* ===== 导航栏（共享）===== */
/* ===== 模块A：书籍卡片 ===== */
/* ===== 模块B：介绍页 ===== */
/* ===== 模块C：管理员页 ===== */
```

### `README.md` 贡献者名单
内置一份名单，每位同学都在同一列表中追加自己一行 → 经典「相邻行冲突」练习。

## 五、README 分支练习指南

- 建分支：`feature/books`、`feature/about`、`feature/librarian`
- 各分支职责、提交、推送、合并流程
- 冲突演练场景：在 `style.css` / `README.md` 上制造冲突，并用 `git status`、冲突标记、`git add` / `commit` 解决

## 六、技术约定

- 纯 HTML + CSS，不写 JS（尊重「纯 HTML 工程」）
- 响应式（媒体查询）+ CSS 变量主题色
- 无构建工具、无后端，浏览器直接打开

## 七、文件归属与冲突矩阵

| 文件 | 归属 | 合并预期 |
|------|------|----------|
| `index.html` | 模块 A（轻度共享） | 多半干净合并 |
| `about.html` | 模块 B | 干净合并 |
| `librarian.html` | 模块 C | 干净合并 |
| `css/style.css` | 全员共享 | **冲突点 ①** |
| `README.md` | 全员共享 | **冲突点 ②** |
| `.gitignore` | 初始建立 | 不变 |
